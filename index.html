Prototype · 5-Minuten-Polling

Der Tagesplan für 6C wird automatisch neu berechnet.

Das Prototype zeigt, wie ein Dienst alle 5 Minuten den IServ-Vertretungsplan abruft, Änderungen erkennt und daraus einen lesbaren Tagesstundenplan für die Klasse 6C erzeugt. Die Oberfläche ist absichtlich einfach gehalten, damit du schnell testen kannst, ob die Logik für Schüler:innen wirklich hilfreich ist.

Technischer Ablauf

1. Quelle prüfenPDF von IServ für das heutige Datum laden.
2. Änderungen erkennenText extrahieren, normalisieren und mit der letzten Version vergleichen.
3. Stundenplan mappenDen Untis-Klassenplan 6C für den Wochentag laden und in Unterrichtsblöcke umformen.
4. Tagesplan erzeugenVertretungen, Raumwechsel und Ausfälle auf die passenden Stunden anwenden.
5. Ergebnis veröffentlichenJSON + HTML neu schreiben und per GitHub Pages oder Cloudflare Pages teilen.

Was schon funktioniert

Statische Web-App als klickbarer Prototype.
Polling- und Parsing-Skript als Startpunkt für die Automatisierung.
Deploy-Struktur für GitHub Pages oder Cloudflare Pages.

Was als Nächstes gebaut werden sollte

PDF-Parser für das konkrete Tabellenlayout des Vertretungsplans finalisieren.
Stundenplan-Extraktion aus der Untis-HTML für alle Wochentage robust machen.
Klassenfilter, Push-Benachrichtigung und Historie der Änderungen ergänzen.

Deployment-Tipp: Lege diese Datei in ein GitHub-Repository und aktiviere GitHub Pages. Die Automatisierung kann dann per GitHub Actions alle 5 Minuten neue Daten erzeugen.
